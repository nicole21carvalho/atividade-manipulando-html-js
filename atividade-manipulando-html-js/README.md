# Atividade - Manipulando Elementos HTML e Funções em JavaScript

Este projeto resolve a atividade solicitada no material da aula.

## O que foi feito

1. A função `entrar()` foi modificada para pedir:
   - Nome do usuário
   - Curso do usuário

2. A mensagem exibida ficou:
   - `Bem-vindo, [nome], ao curso de [curso]!`

3. Foi criada a função:
   - `mediaTresNotas(nota1, nota2, nota3)`

4. A função calcula a média das três notas e informa no console:
   - Aluno aprovado, se a média for maior ou igual a 7
   - Aluno reprovado, se a média for menor que 7

5. A página foi estilizada com CSS:
   - Cor de fundo
   - Fonte
   - Botões maiores
   - Conteúdo centralizado

## Como abrir no VS Code

1. Extraia o arquivo ZIP.
2. Abra o VS Code.
3. Clique em `File > Open Folder`.
4. Selecione a pasta `atividade-manipulando-html-js`.
5. Abra o arquivo `index.html`.
6. Clique com o botão direito no `index.html` e escolha `Open with Live Server`.

Caso não tenha Live Server, basta abrir o arquivo `index.html` no navegador.
