Atividade - Manipulando Elementos HTML e Funções em JavaScript
Este projeto resolve a atividade solicitada no material da aula.

O que foi feito
A função entrar() foi modificada para pedir:

Nome do usuário
Curso do usuário
A mensagem exibida ficou:

Bem-vindo, [nome], ao curso de [curso]!
Foi criada a função:

mediaTresNotas(nota1, nota2, nota3)
A função calcula a média das três notas e informa no console:

Aluno aprovado, se a média for maior ou igual a 7
Aluno reprovado, se a média for menor que 7

Como abrir no VS Code
Extraia o arquivo ZIP.
Abra o VS Code.
Clique em File > Open Folder.
Selecione a pasta atividade-manipulando-html-js.
Abra o arquivo index.html.
Clique com o botão direito no index.html e escolha Open with Live Server.
Caso não tenha Live Server, basta abrir o arquivo index.html no navegador.
